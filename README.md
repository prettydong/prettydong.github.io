# Terminal Workbench

浏览器内的本地终端工作台。使用 React、TypeScript 和 Vite；文件与设置保存在 IndexedDB，不访问真实操作系统或自建执行服务器。

完整欢迎牌是一张透明剪纸插画：阿拉蕾和皮拉夫大王举着带有复古奇幻游戏字形的 **Zed System** 牌，底部写着 **Designed by Zed Huang**。欢迎牌占 6 行文字高度；深色主题使用原剪纸图和主题色，亮色主题使用留白与线条对调的专用图片，线条与文字跟随终端字体颜色，均不使用渐变。

## 运行

```bash
npm install
npm run dev
```

打开 Vite 显示的本地地址。运行 `npm run build` 可执行类型检查并生成生产文件。

## 命令

`help`、`pwd`、`ls [路径]`、`tree [路径]`、`cd [路径]`、`cat <文件>`、`head [-n 数量] <文件>`、`tail [-n 数量] <文件>`、`wc <文件>`、`stat <路径>`、`mkdir <目录>`、`touch <文件>`、`edit <文件>`、`cp <源> <目标>`、`mv <源> <目标>`、`rm [-r] <路径>`、`find [路径] [名称片段]`、`grep <文本> [路径]`、`import [目录]`、`export <文件>`、`echo [文本]`、`date`、`history [数量]`、`python`、`set`、`theme`、`font`、`background`、`clear`、`blog [文章名]`、`game`、`agent`、`reboot`。

路径支持绝对路径、相对路径、`.`、`..` 与 `~`；带空格的路径可用引号包住。按 `Tab` 补全命令、主题名、字体、背景图片开关与文件路径；多个匹配项可继续按 `Tab` 切换。`cp`、`mv` 可处理文件或整棵目录；目标已存在且为目录时，源会放入该目录，重名时拒绝覆盖。`rm` 删除文件，删除目录须用 `rm -r`；根目录和当前目录受保护。`find` 按名称片段查找，`grep` 按文本逐行查找，均会遍历指定目录及子目录，最多显示 200 条结果。`import` 会在终端显示文件选择按钮，可一次导入多个 UTF-8 文本文件到指定目录；每个文件上限 2 MB，重名时整批拒绝。`export` 会显示单个文本文件的下载按钮。`cat README.md` 会在终端内渲染 Markdown（含表格、任务列表和带语法颜色的代码块），其他文本文件仍按原文逐行显示。`edit` 在终端内打开已有文本文件，按 `Ctrl/⌘ S` 保存、`Esc` 关闭。顶栏显示文件和保存状态，底栏显示快捷键。`font pixel` 切换简体中文像素字体，`font mono` 恢复 Maple Mono；`set font 15` 调整字号，像素字体在 12px 时最清晰。`set wrap on` 可调整输出换行；`set background #202020` 设置纯色背景，`set background default` 恢复主题底色。`background on` / `background off` 显示或隐藏右下角剪纸背景，设置刷新后保留；剪纸颜色随主题变化。输入 `theme` 打开主题选择列表，使用方向键、Enter 和 Esc 操作；也可直接输入 `theme codex`、`theme monokai` 或 `theme claude`，其中 `theme monaka` 是 Monokai 的别名。首次启动会创建 `/workspace`、示例目录和欢迎文件；此后不会重新覆盖文件。

`tree` 以树形显示目录，最多列出 200 项。`head` / `tail` 默认读取前 / 后 10 行，`-n` 可指定 0 到 200 行。`wc` 显示逻辑行数、空白分隔的词数、Unicode 字符数与 UTF-8 字节数。`stat` 查看类型、大小与修改时间。`history` 默认显示最近 20 条命令，最多可指定 80 条。`date` 使用浏览器所在设备的本地时间；`echo` 仅输出文本，不支持 shell 重定向。

`reboot` 刷新当前页面，效果等同于浏览器刷新按钮；保留已保存的工作区文件、设置和命令历史，重置当前界面及 Python 会话。支持 Tab 补全，不接受参数。

## 博客

网站默认打开博客欢迎页，可从底栏或按 Esc 返回终端。个人站点部署及推送更新见 [GitHub Pages 部署](docs/github-pages.md)。

输入 `blog` 打开欢迎页，点击“浏览文章”或按 Enter 进入文章列表；输入 `blog <文章名>` 直接阅读。欢迎页插画为布尔玛开发时间机器，机身、袖章和腰间徽章使用 OpenAI 标志。欢迎页左侧为插画，右侧介绍 Zed Huang 的 AI Agent 开发方向及 NBA、游戏爱好；手机端上下排列。点击插画或“浏览文章”后，插画动态缩至原尺寸的三分之一，和精简介绍一起移到顶部，文章列表随后淡入；按 Enter 也有同样效果。博客内不显示终端的超四悟空背景。列表、搜索栏和正文采用居中限宽布局，两侧留白，正文保持左对齐。系统开启“减少动态效果”时直接切换布局。命令和文章名支持 Tab 补全。搜索匹配标题、日期和正文，空格分隔的关键词需要全部匹配。列表按文件名中的日期倒序排列，阅读时保留主题、代码高亮、表格和 Markdown 排版。手机可点击文章、清空搜索、返回列表或终端。

文章维护在项目根目录的 `blog/`，每个 `.md` 文件对应一篇文章，`README.md` 除外。首个一级标题作为标题，文件名采用 `YYYY-MM-DD-slug.md`，例如 `blog/2026-09-26-welcome.md`；直接打开的命令是 `blog 2026-09-26-welcome`。文章顶部 YAML 元数据填写 `abstract` 摘要和 `creators` 创作者数组：本人显示小手，AI 显示对应厂商 logo，混合写作并排显示多个标记。列表仅在文章获得焦点时展开该篇摘要，正文始终显示摘要；创作者标记始终展示，搜索也匹配摘要和创作者名称。新增或修改内容后重新运行 `npm run build` 并部署，所有访客读取相同的编译内容；不通过终端虚拟文件系统发布。写作格式见 [blog/README.md](blog/README.md)。

- 所有博客页面：`Tab` / `Shift+Tab` 向后 / 向前循环当前页所有可用操作，始终留在博客内。范围包括插画入口、搜索框、可用的清空按钮、文章或正文链接、底栏返回操作；隐藏及禁用项会跳过。小箭头跟随实际焦点，不显示按钮边框或高亮底色。
- 欢迎页：点击插画或“浏览文章”进入列表；方向键也可选择入口和返回操作，`Enter` / `Space` 激活当前按钮，`Esc` 返回终端。
- 列表：`/` 聚焦搜索并选中文字；搜索框内 `Enter` 打开首条匹配文章，没有结果时保持搜索。`↓` 从搜索框进入首篇，`↑` 从首篇回到搜索框，搜索框内 `↑` 选择末篇。`Home` / `End` 在输入框外选择首篇 / 末篇。Tab 循环始终可以回到搜索，即使没有结果。
- 阅读：`↑` / `↓` 滚动，`PageUp` / `PageDown` 翻页，`Home` / `End` 跳到开头 / 结尾；正文焦点处 `Space` / `Shift+Space` 向下 / 向上翻页。Tab 包含正文、链接和底栏，`Enter` 打开当前链接或激活当前按钮。
- 非输入状态按 `H` 返回首页。`Esc` 从阅读返回列表；列表中有搜索条件时先清空，再按一次退出；欢迎页直接退出。返回列表保留搜索、选中文章和滚动位置，退出恢复终端焦点与历史阅读位置。手机可点击所有必要操作。

输入法组合输入和选词期间不触发上述快捷键。浏览器带 Ctrl/⌘/Alt 的组合键保留原有行为。

## 游戏

输入 `game` 在命令历史下方展开游戏选单，保留终端顶栏和历史内容。选单为无边框的单行列表，每款游戏一行，显示编号、名称、简介和最高分；窄屏收起简介。右侧保留一个随选择切换的共享棋盘预览，手机上预览移到列表下方。选中行使用主题色文字和浅色底纹，箭头标记实际焦点；点击或方向键切换预览，Enter 或点击预览旁“开始”进入游戏。只有开始具体游戏后才展开整个终端，返回列表时收回到内联选单。

游戏沿用终端的等宽字体和主题色：方块蛇身、字符式食物、线框数字棋盘。顶栏显示游戏及状态，棋盘上方显示得分、最高分与等级或步数，底栏显示快捷键和返回入口。按钮保持纯文字；列表和棋盘的键盘焦点用小箭头标记，其他操作使用细中性色轮廓。棋盘不再套外框，贪吃蛇用四角标记界定边界。

| 操作 | 快捷键 |
| --- | --- |
| 选单切换游戏 | ↑ / ↓ / ← / → 循环；1–9 选择对应编号（存在时） |
| 选单快速定位 | Home / End 首尾；PageUp / PageDown 向前 / 后跳 10 项，到首尾停止 |
| 选单开始游戏 | 游戏行上按 Enter，或激活预览旁“开始”；Space 在游戏行上选择预览 |
| 游戏方向 | ↑ / ↓ / ← / → 或 W / S / A / D |
| 贪吃蛇开始、暂停、继续 | 棋盘上按 Space / Enter，或点击对应按钮 |
| 2048 达到目标后继续 | 棋盘上按 Enter / Space，或点击“继续游戏” |
| 游戏结束后再来一局 | 棋盘上按 Enter / Space，或点击“再来一局” |
| 2048 撤销上一步 | U，或点击“撤销”；连续两次撤销不可用 |
| 重新开始本局 | R，或点击“重开” |
| 切换可用操作 | Tab / Shift+Tab，包含棋盘、方向按钮及底栏，跳过禁用操作并首尾循环 |
| 返回 | Esc：游戏回到列表，列表回到终端 |
| 浏览器全屏 | 游戏内按 F，或点击“全屏”；Esc 先退出浏览器全屏，再按一次返回列表 |

手机可滑动棋盘或点击方向按钮，横屏时棋盘与计分、操作区并排。贪吃蛇支持手指不离屏连续转向；在待开始、暂停或结束状态可直接点棋盘开始、继续或重开。2048 达成目标后也可点棋盘继续。按钮聚焦时 Enter / Space 激活该按钮；输入法组合输入期间不触发游戏快捷键，Ctrl/⌘/Alt 组合键保留浏览器行为。退出游戏模块后恢复终端焦点和阅读位置。

贪吃蛇使用 18×18 棋盘，初始每 140 毫秒移动一格，每吃一个食物得 10 分；每 50 分升一级、间隔缩短 10 毫秒，最高 8 级（70 毫秒）。不能直接掉头，可缓冲两次转向；碰墙或碰到蛇身结束，尾巴正在离开的格子可以通过，填满棋盘获胜。开始时等待方向输入或开始操作。切换标签页或浏览器失去焦点时自动暂停，返回后手动继续。移动带短暂插值，进食有字符粒子和浮动得分，碰撞有短暂角标扩散反馈，食物带轻微脉动。

2048 使用 4×4 棋盘，从两个随机方块开始。每次移动中，每个方块最多合并一次；只有棋盘发生变化才生成新方块，新方块为 2 或 4，概率分别为 90% 和 10%。合并数字累加为得分；达到 2048 后可以继续，无可用移动时结束。方块带滑动、合并和生成动画，合并处显示新增分数与短暂角标。快速输入最多缓冲 3 次方向，按顺序在当前滑动完成后执行；撤销、重开、返回和失焦会清空缓冲。撤销恢复上一有效移动前的棋盘、得分和步数，最高分不会回退。系统设置“减少动态效果”时关闭位移动画和粒子效果。

各游戏的最高分自动保存在当前浏览器的 localStorage，同时记录贪吃蛇最长长度和 2048 最大方块。刷新或重开不会清除纪录；清除站点数据会删除纪录。存储不可用时仍可游玩，纪录仅保留在本次游戏模块会话。本局棋盘不持久化，返回列表再开始、重开或刷新会开启新局。

选单目录位于 `src/games/catalog.ts`，选单渲染和导航按目录长度工作；新增游戏仍需接入对应规则、绘制和纪录类型。游戏规则位于 `src/games/engine.ts`，画面由 `src/games/draw.ts` 绘制，纪录读写在 `src/games/records.ts`，界面和输入在 `src/Games.tsx`。游戏模块提供 `window.render_game_to_text()` 状态快照（含纪录、等级、撤销状态和待执行方向）和 `window.advanceTime(ms)` 手动时钟接口，退出时移除。调用手动时钟后停止自动计时，直到重新进入游戏模块；单次推进最多 60 秒。

## Agent

输入 `agent` 进入终端内联对话模式。顶栏显示工作目录及连接/运行状态；消息支持流式显示，工具结果可展开查看。Enter 发送，运行中 Enter 补充指令、Alt+Enter 排队后续任务，Shift+Enter 换行；Tab / Shift+Tab 循环切换当前模式的可用操作，Esc 先停止、空闲时返回终端。Ctrl+C 在无文本选区时停止当前任务。底栏保留停止、清空和返回操作。输入法组合输入期间不触发快捷键，向上阅读时新消息不会强制滚到底部。

核心采用 Pi agent loop 的浏览器适配版本，支持工具多轮循环、消息/工具事件、取消、上下文转换和轮次上限。已接入浏览器工作区的 `list_files`、`read_file`、`write_file`、`edit_file`；只访问 `/workspace` 下的 IndexedDB 文件。

内置 Python 和博客写作插件，输入 `/plugins` 查看。可以直接说“用 Python 分析 notes/data.csv，把结果保存为 notes/result.json”，或“参考现有博客，写一篇 Python 学习笔记并预览”。Python 在独立 Pyodide 工作线程中执行，支持标准库和按 import 自动加载的 Pyodide 包；默认超时 60 秒，可停止。执行成功才保存新增或修改的工作区文本文件。

博客插件支持检索已发布文章和草稿、分页读取、创建与修改草稿、预览和下载 Markdown，修改前校验版本。草稿持久化到 `/workspace/blog-drafts/YYYY-MM-DD-slug.md`，自动写入摘要和当前服务商的创作者标记；不会自动发布到公开博客。预览中的下载链接可用 Tab 聚焦、Enter 激活，手机可直接点击。发布时把下载文件放入项目 `blog/` 后按原流程构建部署。插件接口与开发说明见 [docs/agent-plugins.md](docs/agent-plugins.md)。

支持 OpenAI 兼容的 Chat Completions API。在本机运行 `npm run agent:configure`，默认使用 DeepSeek（`https://api.deepseek.com` / `deepseek-flash`），也可输入其他地址和模型。API key 和至少 8 字符的解锁密码均隐藏输入，只把加密配置写入源码；构建部署后，进入 `agent` 输入密码解锁。底栏可锁定，退出或刷新也会锁定，明文凭据不写入浏览器存储。密码用于解密，知道密码的人仍可从浏览器取得 key；若需要对用户隐藏 key，应使用后端代理。

解锁后可调整思考强度（关闭 / 低 / 高 / 最高）和每次模型请求的输出上限，默认高强度、8192 tokens；设置本地保存。思考内容单独流式显示、结束后折叠，工具调用时完整保留思考上下文。统计统一放在单行底栏，左侧显示 ↑ 输入、↓ 输出、Σ 合计、R 缓存、T 思考，右侧为模型、思考档位与输出上限；点击用量标签切换会话、任务、最近请求，最近请求显示耗时与首段响应时间。正文不插入统计表或回复小字，所有文字使用终端字号；窄屏底栏可横向查看。仅使用接口报告的用量，缺失时标为未知；思考已包含在输出中。顶栏显示等待、思考、回复和工具执行阶段。

输入 `/help` 查看操作，`/think off|low|high|max` 调整思考强度，`/limit 8192` 设置输出上限，`/usage [session|run|last]` 切换底栏统计，`/clear` 清空对话和计数，`/stop` 停止，`/lock` 锁定，`/exit` 返回终端。这些指令不发送给模型；以 `//` 开头可发送普通斜杠文本。所有控制可通过 Tab / Shift+Tab 和 Enter 操作，运行中设置保持固定。

仍可通过 `configureAgent({ streamFn })` 注入自定义模型流。未配置时显示“未连接模型接口”，草稿可编辑，发送禁用。退出模式清除对话，成功的文件修改仍会保留。接入命令需要 Node 22.18+，浏览器解锁需要 HTTPS 或 localhost，接口须允许 CORS。

完整接口、快捷键、能力边界和接入示例见 [docs/agent.md](docs/agent.md)。上游固定版本、移植差异和 MIT 许可证见 [third-party/pi-agent-core](third-party/pi-agent-core/README.md)。运行 `npm run test:agent` 验证核心循环与工具契约。

## Python

输入 `python` 打开交互式命令行，支持表达式结果、变量、多行代码和上下键浏览本次会话的输入历史；输入 `exit()` 或在空提示符按 `Ctrl+D` 退出。也可以用 `python -c 'print(1 + 1)'` 运行一段代码，或先创建并编辑 `hello.py`，再输入 `python hello.py`。`py` 和 `python3` 是别名。Python 在独立的浏览器 Worker 中运行，首次使用时从 jsDelivr 加载固定版本的 Pyodide；之后由浏览器缓存。运行前将 `/workspace` 下的文本文件复制到 Python 虚拟文件系统，运行后把新增、修改和删除的文本文件同步回 IndexedDB。Python 当前仅支持在 `/workspace` 下运行，文件须为 UTF-8 文本；`input()` 和 `pip` 命令暂未接入。Python 不会访问电脑的真实文件系统。

## 个人导航

输入 `portal` 或别名 `nav` 打开固定网站导航，按 AI、开发、阅读、日常分类。输入关键词可筛选名称、用途、域名和分类；点击“Google 搜索”在新标签页搜索，搜索框内按 Enter 不跳转。网站链接也在新标签页打开。使用 Tab 循环选择网站，按 Esc 或点击底栏“返回终端”退出，保留终端历史和阅读位置。导航不保存筛选条件，不提供链接编辑；网站列表维护在 `src/Portal.tsx`。

### 导航快捷键

- `Alt+Shift+P`：从普通终端进入导航，或返回终端；保留未提交的命令草稿。编辑器、Python 和主题选择中不触发。
- `/`：焦点不在输入框时，聚焦搜索并选中现有关键词，方便直接替换。
- `↑` / `↓` / `←` / `→`：按页面实际位置选择网站，桌面可左右跨列；在搜索框按下键从第一个开始，上键从最后一个开始，左右键仍移动文字光标；没有相邻网站时停留。
- `Home` / `End`：焦点不在输入框时，选择第一个 / 最后一个网站。
- `Enter`：打开已聚焦的网站或激活按钮；搜索框内单独按 Enter 不跳转。
- `1`–`8`：焦点不在输入框时，打开当前筛选结果中对应编号的网站；编号随筛选更新。
- `Ctrl/⌘+Enter`：用 Google 搜索当前非空关键词。
- `Tab` / `Shift+Tab`：按当前网站编号向后 / 向前循环选择，首尾相接；从搜索框开始时选择首个 / 末个网站，没有结果时留在搜索框，不使用浏览器默认焦点遍历。`Esc`：返回终端。

输入法选词期间不触发上述快捷键；数字和 `/` 在搜索框中正常输入。

导航搜索支持空格分隔的多个关键词（全部匹配），以及 B站、Wikipedia、开源、前端等常用别名。搜索栏始终可见，网站区域独立滚动；修改关键词会回到结果顶部。悬停链接可查看域名和打开方式。

## HTTP 探测

`httping <域名或网址>` 探测 HTTP 请求耗时，`ping` 是相同命令的别名，不发送 ICMP 包。

```sh
httping example.com
ping -c 3 https://example.com/
httping -c 1 http://localhost:5173/
```

裸域名默认使用 HTTPS；`-c` 指定 1–20 次，默认 4 次。使用 HEAD 请求，每次最多等待 5 秒，请求结束后间隔 1 秒继续。逐条输出响应、超时或失败，结束时统计收到响应的请求耗时 min / avg / max。计时到 fetch 返回响应为止，可能包含 DNS、连接、TLS、重定向和服务器处理时间，不代表 ICMP 延迟。

跨域探测使用 `no-cors`，浏览器通常不允许读取 HTTP 状态码，此时显示“收到响应 · 跨域状态不可读”，不代表 HTTP 成功；同源可读状态如 200、404 按实际显示，错误状态仍计入收到响应。请求失败也可能由浏览器策略、HTTPS 页面访问 HTTP、证书或网络错误导致，不能直接判断目标离线。HEAD 不受支持时不会自动改用 GET。探测不携带 Cookie 或网址内凭据，并请求禁用 HTTP 缓存；不增加后端服务。

运行中按 `Ctrl+C` 或 `Esc` 停止；`Tab` / `Shift+Tab` 固定选择“停止探测”，`Enter` 激活，不使用默认焦点遍历。手机可点击底栏“停止探测”。停止会取消正在进行的请求或等待，并保留已有结果，输入法选词期间不触发工具快捷键。


## CPU 信息

输入 `lscpu` 运行约 2 秒的趣味单线程跑分，输出逻辑线程数、分数和相对 Apple M4 的性能倍数。跑分在独立 Worker 中执行整数运算与浮点运算，预热后各采样三次取中位数，主界面保持可操作。

参考值来自 2026-09-26 在 Apple M4、Chromium 154 上的三次实际运行：整数 620232704 次/秒，浮点 207159296 次/秒。两项相对吞吐量的几何平均值 × 1000 为分数，Apple M4 参考分数为 1000。它只对比这一小段 JS 的单线程表现，用于娱乐，不识别真实 CPU 型号，也不换算多核性能；浏览器和负载会影响分数。

运行时 `Ctrl+C` / `Esc` 停止，`Tab` / `Shift+Tab` 选择“停止跑分”，`Enter` 激活，手机也可点击停止。

导航网站的 `>` 与高亮统一跟随实际焦点。浏览网站时移动鼠标可切换选中项；输入框正在编辑时，悬停不抢焦点。方向键上下移动限定在同一列，左右键跨列，Tab 按编号循环。拖选终端输出不会自动抢回命令输入焦点。输入框及编辑器使用原生块状光标，支持 `caret-shape` 的浏览器会以字符块显示插入位置。


## 浏览器存储

输入 `df` 查看本站的已用空间、浏览器存储配额、可用配额及使用率，自动使用 B / KiB / MiB / GiB 等单位。数据来自 `navigator.storage.estimate()`，覆盖浏览器为当前来源统计的存储（包括工作区 IndexedDB），不代表整块磁盘或所有网站的 HTTP 缓存。命令支持 Tab 补全，不修改或清理数据。

## 界面配色

界面以主文字色和灰色为主，标题、目录、链接与当前选中项使用少量主题色。导航仅分类标题分色，网站名称保持主文字色；日期、编号和快捷键使用灰色。保存、运行和错误状态保留语义色，Markdown 与代码保留语法配色。切换主题时同步更新颜色，快捷键与操作方式保持一致。

普通按钮在悬停、点击和选中时保持原有文字与背景颜色。游戏选单例外：选中行使用主题色文字和浅色底纹，保留共享预览；列表和棋盘用小箭头表示实际焦点，不加外框。博客使用小箭头表示实际焦点，不显示按钮边框。其他操作的键盘焦点使用细中性色轮廓，主题选择和命令补全保留文字选中标记。
