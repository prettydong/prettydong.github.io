# 从这里开始

Zed System 是 Zed Huang 的个人终端工作台。打开网页，从一行命令开始：读一篇文章、写一段代码、整理文件，或进入常用网站导航。

整个项目围绕一个全屏终端展开。顶栏显示当前所在的位置，底栏列出当前可用的快捷键，中间留给内容。博客、编辑器和 Python 都在这个界面里切换。

## 从几条命令开始

输入 `help` 查看命令，输入 `blog` 阅读文章，输入 `portal` 打开按 AI、开发、阅读和日常分类的网站导航。

工作区提供目录和文本文件管理。可以用 `ls`、`tree` 查看文件，用 `cat` 阅读 Markdown，用 `edit` 编辑文本，也可以导入或导出文件。输入 `python` 进入交互环境，试算一个表达式，或运行工作区里的脚本。

另外还有几个小工具：`httping` 测量 HTTP 请求耗时，`lscpu` 运行一段浏览器内的计算测试，`df` 查看本站的浏览器存储用量。

## 用键盘浏览，也能用鼠标停留

终端通过 Tab 补全命令；进入博客后，Tab 和 Shift+Tab 在可用操作之间循环，小箭头标出当前位置。选中文章时展开摘要，打开后阅读完整正文。返回列表时，搜索条件和阅读位置会保留。

每篇文章都有独立摘要和创作者标记。小手表示 Zed Huang 创作，AI 厂商标志表示对应 AI 参与；共同写作的文章会并排展示多个标记。

主题、字体和剪纸插画构成了这个工作台的外观。可以用 `theme` 切换配色，用 `font pixel` 切换像素字体；文字、代码高亮和图标会跟随主题变化。手机上也保留了浏览文章、返回和停止任务等可点击操作。

## 内容放在哪里

项目使用 React、TypeScript 和 Vite 构建。个人工作区的文件与设置保存在当前浏览器中，Python 通过 Pyodide 在独立 Worker 里运行。

博客文章则来自项目里的 Markdown 文件，随网站构建一起发布。访客读到相同的文章，各自在终端里编辑的本地文件留在自己的浏览器中。

这个博客会记录 AI Agent 的开发实践与技术思考，也会写到 NBA 和游戏。这里是入口，后面的文章慢慢展开。
